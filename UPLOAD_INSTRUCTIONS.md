# Add to the existing Venesse repository

1. Extract the ZIP on your computer.
2. Open your existing Venesse-retail-analytics repository on GitHub.
3. Use Add file → Upload files. Drag the entire Python folder into the upload area, preserving its folder structure. Check that the preview paths begin with Python/.
4. Review the upload, then commit with a message such as: Add Python business agent and desktop reporting interface.
5. Open the repository’s existing root README.md and choose Edit. Append the contents of README_SECTION_TO_APPEND.md, then preview the Python link before committing.

Upload the Python folder only. README_SECTION_TO_APPEND.md and this instructions file are local guides. Do not replace your existing root README with Python/README.md. If a Python folder already exists, compare its contents before uploading files with matching names.

The working PyCharm project is unchanged. The portfolio copy uses VENESSE_DB_SERVER instead of a personal server name. Set that environment variable when running this copy. Preserve your existing private AI run settings. Reports, keys, usage logs, virtual environments, and PyCharm settings are excluded.

Repository inspection was unavailable through the web view, so these additions are prepared without assuming the names of your existing SQL/DAX/Power BI directories. Nothing has been uploaded or committed by Codex.
